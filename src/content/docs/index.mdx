## What's inside this toolkit?

This site is the docs face of the [`specialization-sap-on-azure`](https://github.com) innersource repo — it combines audit guidance, an engagement playbook, downloadable Word/PowerPoint/Excel workfiles, and a GitHub Custom Agent that knows the SAP-on-Azure architectural surface end-to-end.
