## What is the SAP on Microsoft Azure Advanced Specialization?

The **SAP on Microsoft Azure Advanced Specialization** is a Microsoft Partner credential that validates deep technical expertise in planning, migrating, and running SAP workloads on Microsoft Azure — including S/4HANA, BW/4HANA, classic ECC, and the surrounding SAP landscape. It signals to customers and Microsoft that your organisation:

- Has **proven delivery capability** for SAP workloads on Azure
- Generates **measurable Azure consumed revenue** from SAP customers
- Employs **certified or trained professionals** on the AZ-120 / Run-SAP-on-Microsoft-Cloud syllabus
- Has passed a rigorous **independent third-party audit** validating processes and customer outcomes

<Aside type="tip">
  Partners with this specialization typically appear higher in Microsoft Partner Finder for SAP
  workloads, qualify for additional co-sell benefits, and gain access to Microsoft-funded marketing
  programmes targeted at SAP customers.
</Aside>

## Why pursue this specialization?

The SAP on Azure pipeline is large and concentrated — a small number of SAP-on-Azure-credentialed partners win a disproportionate share of S/4HANA-on-Azure deals.

| Benefit | Details |
|---|---|
| **Differentiation** | A verifiable, audited credential in a market where customers care intensely about reference experience |
| **Co-sell eligibility** | Priority co-sell referrals from Microsoft field sellers and the SAP CoE |
| **Marketing assets** | Specialization badge + Microsoft-approved collateral aimed at SAP buyers |
| **Partner Finder visibility** | Appear in SAP-on-Azure-filtered customer searches |
| **Customer confidence** | Demonstrate credibility on a workload where downtime cost is measured in &euro;100k/hour |

## How this toolkit helps

This repository is structured as a **complete engagement toolkit**, not just an audit checklist:

1. **Audit preparation** — every Module A and Module B control mapped to a page with evidence checklist, guidance, and common gaps.
2. **Engagement playbook** — offering one-pager, qualification questionnaire (SAP estate + HANA sizing + RISE vs self-managed), 3-day discovery workshop, WAF assessment (Reliability + Performance first), Azure Migrate / ACSS readiness, reference architectures, and customer deliverables.
3. **Downloadable workfiles** — Word, PowerPoint, Excel templates under `/templates/` so consultants take real artefacts into customer meetings.
4. **GitHub Issues** — the audit task board, auto-recreated annually.
5. **Engagement Agent** — a GitHub Custom Agent that routes consultant questions to the right page and surfaces blockers first.

## Specialization scope

| Module | Scope |
|---|---|

| **Module B** | SAP on Microsoft Azure — delivery capability, ACR, skilling, partner onboarding assets |

## Delivery model variants covered

Both delivery models are in scope for the offering:

- **Self-managed SAP on Azure** — partner owns IaaS through SAP Basis end-to-end.
- **RISE with SAP on Azure** — partner owns the Azure landing zone, peering, identity integration, and monitoring hand-off; SAP runs the SAP layer.

The engagement playbook calls out which questions, templates, and architecture decisions change between the two.
