## What the Auditor Checks

The auditor verifies that you have a **working complaint-handling process** — that complaints are captured, root-caused, and resolved, with corrective actions feeding back into delivery.

**Typical questions:**

- Where is your complaint-handling process documented?
- Can you show a complaint register?
- Walk us through one resolved complaint, end to end.

---

## Required Evidence Checklist

- [ ] **Documented complaint-handling process** — PDF / Word  
  _Cover: channels (email, portal, account manager), SLAs (acknowledge, investigate, resolve), severity classification, escalation path, and the root-cause / corrective-action link._
- [ ] **Complaint register** (may be empty if a signed declaration is attached) — Excel / PDF  
  _Columns: ID, date, customer (anonymised), channel, severity, summary, owner, status, resolution date, root cause, corrective action ID._
- [ ] **At least one resolved complaint with root cause analysis** (anonymised) — PDF / Word  
  _Format: original complaint → investigation → root cause → corrective action → customer sign-off._
- [ ] **Evidence of corrective actions taken** — PDF / Word

<Aside type="tip">
  An empty complaint register is acceptable only with a signed declaration that there have been no
  complaints in the period. Most auditors prefer at least one documented minor complaint —
  a low-severity service issue handled properly is better than nothing.
</Aside>

## Common Gaps

- **Empty register without a signed declaration:** add a signed declaration.
- **Case lacks root cause:** add an RCA section — even a five-whys analysis is enough.
- **No corrective action:** add a linked action item with owner and due date.
