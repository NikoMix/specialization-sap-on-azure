## What the Auditor Checks

The auditor verifies that your organisation is a **legally registered entity** with a clear organisational structure and identifiable key personnel responsible for SAP-on-Azure service delivery.

**Typical questions:**

- Is the company legally registered in its operating jurisdiction?
- Is there a documented organisational structure showing reporting lines?
- Are key personnel (leadership, SAP practice lead, Azure infra lead, account managers) identifiable?

---

## Required Evidence Checklist

- [ ] **Certificate of Incorporation** or equivalent legal registration document — PDF  
  _A current registry extract (Companies House UK / Handelsregister DE / KvK NL / Secretary of State US) satisfies registration number, address, and incorporation in a single document._
- [ ] **Organisational chart** showing reporting lines and key roles — PDF / PowerPoint / Visio  
  _Must show: leadership layer, SAP practice (Basis / functional / ABAP), Azure infrastructure practice (cloud architects, landing-zone team), delivery management, account management._
- [ ] **List of key personnel** with names, titles, responsibilities, and certifications — PDF / Word / Excel  
  _Use the template below; include at minimum SAP practice lead, Azure infrastructure lead, engagement lead, and account manager._

- [ ] **Registered address** matching official company records — PDF / screenshot

## Common Gaps

- **Org chart doesn't show SAP / Azure split:** add a second tier showing the SAP and Azure practices distinctly.
- **Certificate is more than 3 years old:** request a current extract from the registry.
- **Key personnel list is informal (email thread):** formalise into a signed Word or PDF document.
