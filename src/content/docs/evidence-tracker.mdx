## Pre-Qualification Gate

- [ ] Active Solutions Partner for Infrastructure (Azure) designation confirmed
- [ ] ACR ≥ USD 7,500 over trailing 3 months (SAP-eligible services)
- [ ] ≥ 3 unique customers contributing ACR via DPOR / PAL / CSP
- [ ] AZ-120 holder OR Run-SAP-on-Microsoft-Cloud learning-path completer
- [ ] Microsoft Learn transcript exported for the skilling holder
- [ ] Audit requested via Partner Center
