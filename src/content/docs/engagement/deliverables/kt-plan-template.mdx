## When to use this

Build phase. Knowledge Transfer runs in parallel with build / cutover preparation and concludes
before hypercare exit. The plan should be drafted no later than 4 weeks before go-live so
sessions can be scheduled and attendance confirmed.

<Aside type="tip">
  For a fully detailed, role-based training curriculum with Microsoft Learn module links and a
  13-week delivery schedule, see the
  [Knowledge Transfer Training Guide](/engagement/knowledge-transfer-training-guide/). Use that
  page to drive the training delivery; use this template for the formal sign-off artefact.
</Aside>

---

## Knowledge Transfer objectives

1. The customer's run team can operate the SAP landscape on Azure **independently** within the
   agreed hypercare exit date.
2. The customer's on-call engineers can respond to the Priority 1 and Priority 2 alerts defined
   in the [Hypercare Plan](./hypercare-plan-template/).
3. The customer's Basis team can execute routine operations (patching, backup verification,
   cluster maintenance) without partner assistance.

## Knowledge Transfer modules

### SAP-side modules

| Module | Topics | Target role | Duration |
| :--- | :--- | :--- | :--- |
| KT-S1: HANA daily operations | Start/stop, backup verification, log backup monitoring, space management | SAP Basis | 2 h |
| KT-S2: HANA System Replication | HSR state check, monitoring replication lag, re-register secondary, planned/unplanned takeover | SAP Basis | 3 h |
| KT-S3: ASCS/ERS cluster | Pacemaker status, resource move, STONITH, planned maintenance, failover test | SAP Basis | 2 h |
| KT-S4: SAP kernel & support package patching | Patching steps, transport import, rollback procedure | SAP Basis | 2 h |
| KT-S5: Transport system | Transport routes, buffer management, import queue monitoring | SAP Basis | 1 h |

### Azure-side modules

| Module | Topics | Target role | Duration |
| :--- | :--- | :--- | :--- |
| KT-A1: Azure landing zone | Hub-spoke topology, subscription structure, resource groups, tagging, cost management | Azure infra | 2 h |
| KT-A2: Networking | ExpressRoute health, NSG review, private DNS, load balancer diagnostics | Azure infra | 2 h |
| KT-A3: Identity | Entra ID groups, PIM activation, Fiori SSO configuration, break-glass accounts | Azure infra | 1 h |
| KT-A4: Azure Center for SAP solutions | Landscape view, health check, SAP system management from ACSS | Azure infra + Basis | 1 h |
| KT-A5: Azure Monitor for SAP | Alert rules, action groups, dashboard navigation, alert response steps | Operations | 2 h |
| KT-A6: Azure Backup for SAP HANA | Backup policy review, restore procedure, backup report, job failure triage | Operations | 2 h |
| KT-A7: Azure Update Manager | OS patch policy, SAP kernel update coordination, compliance dashboard | Operations | 1 h |

### Joint modules

| Module | Topics | Audience | Duration |
| :--- | :--- | :--- | :--- |
| KT-J1: Runbook walkthrough | End-to-end runbook review — start/stop, DR failover, on-call procedures | All technical | 2 h |
| KT-J2: Disaster recovery drill | Simulated regional failover — verify RTO/RPO, document gaps, sign off | Basis + Azure | 3 h |

## Delivery schedule

Sessions should be booked at least 2 weeks in advance with attendance mandatory for the
named roles. Record all sessions and make recordings available in the shared project folder.

| Week | Module(s) | Trainer | Attendees | Venue |
| :--- | :--- | :--- | :--- | :--- |
| Week -4 (pre-cutover) | KT-A1, KT-A2, KT-A3 | Azure architect | Azure infra team | Video call + recorded |
| Week -3 | KT-S1, KT-S2 | SAP Basis architect | Basis team | Video call + recorded |
| Week -3 | KT-A4, KT-A5 | Azure architect | Basis + Ops | Video call + recorded |
| Week -2 | KT-S3, KT-S4, KT-S5 | SAP Basis architect | Basis team | Video call + recorded |
| Week -2 | KT-A6, KT-A7 | Azure architect | Operations | Video call + recorded |
| Week -1 | KT-J1 (runbook walkthrough) | Both architects | All technical | On-site or video |

| Hypercare week 2 | KT-J4 (monitoring walkthrough) | Both architects | All on-call | Video call |
