## When to use this

At the hypercare exit review. The customer signs it; you archive it as evidence.

## Definition of Done checklist

### Audit evidence

- [ ] All Module A controls have linked customer evidence (where applicable)
- [ ] All Module B controls have linked customer evidence
- [ ] Evidence index updated in the customer engagement folder

### Architectural sign-off

- [ ] SAP-certified architecture sign-off captured (VM SKUs match the SAP HANA table for the chosen region)
- [ ] HLD v1.0+ signed by customer architecture board
- [ ] LLD v1.0+ signed by customer Basis + infra leads

### Resilience

- [ ] DR drill executed at least once with the customer in attendance
- [ ] DR drill outcome documented in the runbook with RTO/RPO measured against the committed values

### Operations

- [ ] ACSS onboarded for all production systems
- [ ] Azure Monitor for SAP solutions deployed and alert routes confirmed
- [ ] Azure Backup for SAP HANA configured and a restore drill completed
- [ ] Azure Update Manager handling OS patching cadence

### Hypercare

- [ ] Hypercare exit memo signed by the customer
- [ ] X consecutive clean EarlyWatch Alerts (customer-defined X, typically 4 weeks)
- [ ] Zero open P1 defects at exit
- [ ] KT plan signed off — customer's run team is operationally independent
