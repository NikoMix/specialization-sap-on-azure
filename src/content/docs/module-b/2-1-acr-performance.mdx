## What the Auditor Checks

The auditor verifies that your organisation has generated **≥ USD 7,500 of Azure Consumed Revenue over the trailing 3 months** across SAP-on-Azure-eligible Azure services.

**Typical questions:**

- Show me the ACR export from Partner Center.
- Which services in the export are SAP-on-Azure-eligible?
- Is the figure reconciled with your PDM?

---

## Required Evidence Checklist

- [ ] **Partner Center ACR export** for the last 3 months — PDF / Excel
- [ ] **Annotated breakdown** showing only SAP-on-Azure-eligible service spend — PDF / Excel
- [ ] **PDM-confirmed reconciliation** for any borderline subscription category — Email / PDF
- [ ] **Trend chart** showing ≥ 3 consecutive months above threshold — PDF / Excel

<Aside type="tip">
  Partner Center data lags by **2–4 weeks**. Pull the export at least 4 weeks before audit
  submission so you have time to reconcile with your PDM if any service is miscategorised.
</Aside>

---

## Evidence Guidance

### Pulling the ACR Export

Partner Center → **Insights → Azure Revenue**:

1. Set date range to the last 3 full calendar months.
2. Switch view to **By Service** to filter the SAP-eligible service set.
3. Switch view to **By Customer** for the customer diversity evidence used by [B.2.2](../2-2-customer-diversity/).
4. Export both views and date-stamp the filenames.

### Annotating the SAP-Eligible Set

Highlight or filter rows for:

- SAP-certified compute (M / Mv2 / Mv3 series)
- Storage typically used for SAP (Azure NetApp Files, Premium SSD v2, Ultra Disk)
- Network (ExpressRoute) and management (ACSS, Azure Monitor for SAP) where attributable

For mixed-purpose subscriptions, apply a documented allocation rule and include the rule in the evidence pack.

### Reconciliation with PDM

If your figure is close to USD 7,500, email your PDM with the export attached and ask for a current-week sense-check. Save the reply.

## Common Gaps

- **PAL not set up on SAP customer subscriptions:** set up PAL today — it back-fills attribution.
- **ACR includes non-SAP services:** add an annotated breakdown isolating the SAP-eligible spend.
- **Single month above threshold:** delay submission until 3 consecutive months are above.
