The playbook is the delivery motion that produces the Module B evidence. Run it end to end and the
audit package assembles itself as a by-product of real customer work.

The sequence is: **offering one-pager** → **qualification questionnaire** → **discovery workshop** →
**WAF assessment** → **reference architectures** → **HLD / LLD / runbook / KT / hypercare** →
**definition of done**. Every stage has a downloadable workfile under `static/templates/`.
