Module B is the specialization-specific half of the audit. It asks you to prove real SAP workload
delivery on Azure — not general cloud capability — across the SAP-on-Azure service surface:
SAP-certified M / Mv2 / Mv3 VMs, Azure NetApp Files and Premium SSD v2, Availability Zones,
ExpressRoute, HANA System Replication, ASCS/ERS clustering, Azure Center for SAP solutions,
Azure Monitor for SAP solutions, and Azure Backup for SAP HANA.

Start with [1.1 SAP on Azure Implementation](1-1-sap-on-azure-implementation/), which anchors the
technical evidence, then work through ACR, customer diversity, skilling, and the onboarding pack.
The [Reference Architectures](/docs/engagement/reference-architectures) page maps each control back to
a published Microsoft Azure Architecture Center architecture you can cite in evidence.
