## What the Auditor Checks

The auditor verifies that you have a **documented, repeatable delivery methodology** for SAP-on-Azure engagements and that you actually use it — evidenced by project artefacts from a real customer.

**Typical questions:**

- What lifecycle do you use for SAP migrations / greenfield builds on Azure?
- Where is your SOW template? Is it standard across engagements?
- Can you show project artefacts (plan, RACI, status reports) from a recent engagement?

---

## Required Evidence Checklist

- [ ] **Documented delivery methodology** (lifecycle, phases, gates) — PDF / Word
- [ ] **SOW or engagement contract template** — PDF / Word
- [ ] **Sample project plan / WBS** from a real engagement (anonymised) — PDF / Excel / MS Project
- [ ] **Sample status report / steering pack** — PDF / PowerPoint
- [ ] **RACI matrix** for a typical engagement — PDF / Excel

{{% alert type="tip" %}}
For SAP engagements, your methodology should explicitly call out the **SAP Activate** phases
(Discover → Prepare → Explore → Realize → Deploy → Run) and how they map onto your Azure
workstream (landing zone, infra build, cutover, hypercare).
{{% /alert %}}

---

## Evidence Guidance

### Documented Methodology

The auditor wants to see that you have a methodology — not which one. SAP Activate is the natural reference for SAP-on-Azure. Cover at minimum:

- Phases and their entry/exit criteria
- Roles and responsibilities (SAP-side + Azure-side)
- Gate reviews and approval mechanics
- Document control / version management

### SOW Template

The SOW template should include scope, assumptions, dependencies, deliverables, acceptance criteria, change-control process, and pricing model placeholders.

### Project Artefacts

Auditors look for **evidence that the methodology is alive** — provide artefacts from a recent customer engagement (anonymise customer name to "Customer A"). A plan, two status reports, a steering pack, and a sign-off email is a strong set.

## Common Gaps

- **Methodology exists but isn't SAP-aware:** add a one-page mapping to SAP Activate phases.
- **No real artefacts attached:** even one anonymised plan + one status report is enough.
- **Methodology is described in slides only:** convert to a versioned Word / PDF document.
